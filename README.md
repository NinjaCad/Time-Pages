## 🚀 *Playback*

### 🎮 Overview

This project is a 2D puzzle system where the player can switch between multiple characters to solve challenges. Each character can be controlled individually, and their movements are recorded, allowing for coordinated actions across multiple “timelines.”

---

## 🕹️ How to Play

* Use **WASD / Arrow Keys** to move the active character
* Press **1–3** to switch between different characters
* Press **Space** to reset control
* Activate switches to open doors
* Work with multiple characters to solve puzzles

---

## ⚙️ Features

* **Character switching system** (control different players)
* **Movement recording system** (stores player actions over time)
* **Multi-character coordination** for puzzle solving
* **Switch and door mechanics** (trigger-based interactions)
* **Collision management** between multiple player objects
* **Scene reset system**

---
